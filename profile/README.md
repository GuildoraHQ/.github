# Guildora × Mcora

中文的 Discord 伺服器、機器人與 Minecraft 伺服器列表。找到好玩的社群，也讓別人找到你的。

Chinese-language directories for Discord servers, bots and Minecraft servers.

| | |
| --- | --- |
| **[Guildora](https://guildora.net)** | Discord 伺服器、機器人與伺服器範本 |
| **[Mcora](https://mcora.net)** | Minecraft 伺服器列表、投票與排行榜 |
| **[說明文件](https://guildora.net/docs)** | 上架、投票、帳號與開發者指南 |
| **[API 文件](https://guildora.net/reference)** | 公開 API 與 [MCP 伺服器](https://guildora.net/mcp) |
| **[系統狀態](https://status.guildora.net)** | 服務運作狀態與事件紀錄 |
